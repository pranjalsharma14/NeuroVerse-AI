## 🧠 What is NeuroVerse AI Content Studio?
 
**NeuroVerse AI Content Studio** is a full-stack AI-powered content generation platform — built for creators, marketers, startup founders, and developers who want to produce high-quality content at the speed of thought.
 
Think of it as your **all-in-one AI writing co-pilot** that lives in a beautiful, lightweight web app.
 
```
You describe it  →  AI generates it  →  You copy, download, or reuse it.
Done.
```
 
Whether you need a **viral tweet**, a **SEO blog post**, an **investor pitch**, or a **YouTube script** — NeuroVerse has a dedicated AI tool for every content format, powered by the world's best AI models via **OpenRouter**.
 
### The Core Idea
 
Most content tools force you into one model or one format. NeuroVerse is different:
 
- 🎯 **16 specialized content tools** — not one generic chatbox
- 🌐 **Multilingual** — write in English, Hindi, or Hinglish
- 🎨 **10 writing tones** — match your exact brand voice
- 🤖 **6 AI models** — switch between Gemini, GPT, Claude, LLaMA & more
- 💾 **Session history** — every generation saved for reuse
- ✨ **SaaS-grade UI** — built on Streamlit, feels like a product

## 📦 Installation
 
### Prerequisites
 
- Python 3.10 or higher
- An [OpenRouter](https://openrouter.ai) account (free to sign up)
---
 
### Step 1 — Clone the Repository
 
```bash
git clone https://github.com/pranjalsharma14/neuroverse-ai-content-studio.git
cd neuroverse-ai-content-studio
```
 
---
 
### Step 2 — Create a Virtual Environment
 
```bash
# Create
python -m venv venv
 
# Activate (Windows)
venv\Scripts\activate
 
# Activate (Mac / Linux)
source venv/bin/activate
```
 
---
 
### Step 3 — Install Dependencies
 
```bash
pip install -r requirements.txt
```
 
**requirements.txt**
```
streamlit>=1.32.0
openai>=1.14.0
```
 
---
 
### Step 4 — Configure Your API Key
 
```bash
# Create the secrets folder
mkdir .streamlit
```
 
Create the file `.streamlit/secrets.toml` and add:
 
```toml
OPENROUTER_API_KEY = "sk-or-v1-your-key-here"
```
 
> **Get your free API key →** [openrouter.ai/keys](https://openrouter.ai/keys)
 
---
 
### Step 5 — Launch the App
 
```bash
streamlit run app.py
```
 
Open your browser at **http://localhost:8501** — you're live. 🌸

## 🔐 Environment Variables
 
NeuroVerse uses Streamlit's built-in secrets management. **Never hardcode your API key.**
 
```
Project Root/
├── .streamlit/
│   ├── secrets.toml      ← YOUR API KEY (never commit this)
│   └── config.toml       ← Theme & server config
└── app.py
```
 
**`.streamlit/secrets.toml`**
```toml
# OpenRouter API Key
# Get yours free at: https://openrouter.ai/keys
OPENROUTER_API_KEY = "sk-or-v1-xxxxxxxxxxxxxxxxxxxx"
```
 
> ⚠️ Add `.streamlit/secrets.toml` to your `.gitignore` before pushing to GitHub.
 
```bash
echo ".streamlit/secrets.toml" >> .gitignore
```
